Cirrhosis Patient Data Analysis Using SQL

📌 Project Overview

This project uses MySQL to analyze a cirrhosis patient dataset. SQL queries are used to filter patient records, calculate statistics, and explore relationships between clinical measurements, treatment types, disease stages, and patient status.

🎯 Project Objectives

Analyze patient status and demographic information.

Calculate average and maximum clinical measurements.

Compare patient statistics by gender and disease stage.

Explore relationships between ascites, hepatomegaly, and other clinical indicators.

Filter and sort patient records using SQL.

🛠️ Tools & Technologies

Database: MySQL

Query Language: SQL

Concepts: Filtering, Aggregate Functions, GROUP BY, ORDER BY, LIKE, Data Analysis

📊 Analysis Performed

Patient Status Analysis – Retrieve records of censored patients and patients who died.

Age Analysis – Calculate the average age of male patients and identify patients above or below 50 years.

Clinical Measurements – Find average albumin, cholesterol, and prothrombin values, along with maximum bilirubin and platelet ranges.

Disease Indicators – Count patients with both ascites and hepatomegaly.

Gender Analysis – Count male and female patients by disease stage.

Treatment Analysis – Analyze patients receiving D-penicillamine and identify records containing penicillamine in the drug name.

Platelet Analysis – Compare average platelet counts for patients with and without ascites.

Record Sorting – Sort patient records by age, cholesterol, and number of days.

🧠 SQL Concepts Used

SELECT – Retrieve data.

WHERE – Filter records.

AVG() – Calculate averages.

MAX() and MIN() – Find maximum and minimum values.

COUNT() – Count records.

GROUP BY – Group records for analysis.

ORDER BY – Sort results.

LIKE – Search for matching text.
